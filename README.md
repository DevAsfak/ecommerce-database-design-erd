# 🛒 E-Commerce Relational Database & System Architecture

A normalized (3NF) relational database schema designed for scalable e-commerce systems, featuring user management, product inventories, and transactional order tracking.

## 📌 Architecture Highlights
- **3NF Normalization:** Zero redundancy and high data integrity.
- **Relational Integrity:** Foreign key cascading and constraints.
- **Performance Optimized:** Indexing ready for frequent queries (`user_id`, `order_status`).

## 🛠️ Tech Stack & Tools
- **Database:** MySQL / PostgreSQL / MS SQL Server
- **Modeling Tool:** Draw.io / Relational Modeling
- **Language:** SQL (DDL, DML)

## 📁 Repository Structure
- `schema.sql` : Complete SQL DDL script for table creation and relationships.
- `queries.sql` : Essential reporting and operational SQL queries.
